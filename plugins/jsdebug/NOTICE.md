# JavaScript debugger adapter

The optional adapter installer downloads Microsoft's standalone vscode-js-debug 1.140.0 from its official GitHub release and verifies the SHA-256 recorded in adapter.js before extraction. Adapter files, bundled notices, and license files remain in the user's MarinaShell data directory; they are not copied from an editor installation.

Source and license: https://github.com/microsoft/vscode-js-debug/tree/v1.140.0

vscode-js-debug is distributed under the MIT license. Dependencies and their notices are included in the upstream distribution. Custom adapter installations are selected explicitly in Debugger setup.
