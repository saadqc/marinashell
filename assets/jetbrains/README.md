# JetBrains UI assets

Flask, Python and Shell SVGs and font files copied from the locally installed PyCharm application to match the supplied reference. Icons originate in JetBrains/intellij-community (https://github.com/JetBrains/intellij-community); see ICONS-LICENSE.txt. JetBrains Mono and Inter are distributed under the SIL Open Font License; their license files are included here.

uv.svg and uvicorn.svg are original simple marks drawn for MarinaShell: "uv" follows Astral's uv wordmark styling, and the unicorn stands for the uvicorn ASGI server. They are not JetBrains assets.

UI uses Inter at 14 logical pixels and terminal/code uses JetBrains Mono at 13 pixels. The UI retains the original MarinaShell dark palette.
